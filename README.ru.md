# ayla-tools-compact

[English](README.md) · **Русский**

Однострочные строки инструментов для [Pi](https://pi.dev). `bash`, `read`, `grep`, `find` и `ls` рисуются одной строкой вместо блока на всю ширину.

```text
✓ $ pwd && whoami && date 0.0s
  /Users/example
  example
  Tue Oct 19 02:38:11 UTC 2026
```

```text
· grep /renderResult/ --glob extensions/*.ts
  extensions/index.ts: renderResult(result, options, theme, context) {
  extensions/index.ts: return lines((width: number) => {
  … +7 lines · ctrl+o
```

В свёрнутой строке видно 5 строк вывода, а у упавшего вызова 9. `ctrl+o` раскрывает до 400 строк. У шелла в заголовке есть длительность, а в выводе показывается конец, где обычно лежат ошибки; у файловых инструментов показывается начало.

## Установка

Нужен Pi 1.3.0, это проверенная база. Другие версии Pi не проверялись. Пакеты хоста `@earendil-works/pi-coding-agent` и `@earendil-works/pi-tui` даёт сам Pi, поэтому у расширения нет runtime-зависимостей.

```sh
# из git
pi install git:github.com/kekma-dot/ayla-tools-compact

# с фиксацией коммита
pi install git:github.com/kekma-dot/ayla-tools-compact@<commit>

# локальный checkout
pi install ./ayla-tools-compact
```

После установки перезапустите Pi или выполните `/reload`.

## Что меняется

Только отрисовка. Расширение добавляет один resolver отрисовки через публичный хук `pi.registerToolRenderer`. Для пяти имён выше он возвращает `renderCall` и `renderResult` с `renderShell: "self"`. Для любого другого имени вызывается `next()`, и строку рисует Pi.

Инструменты не регистрируются, поэтому исполнение, схемы параметров, права и активный набор инструментов остаются такими, какими их задал Pi. Свой `bash` другого расширения, в том числе sandboxed, сохраняет собственный executor и схему и просто рисуется компактной строкой.

Resolver работает по имени инструмента, поэтому если два расширения рисуют одни и те же имена, результат решает порядок загрузки. Чтобы вернуть отрисовку Pi, уберите или отключите пакет.

## Настройки

`PI_GLAM_TOOLS=0` отключает отрисовку на один запуск. Имя переменной осталось от прежних версий пакета.

```sh
PI_GLAM_TOOLS=0 pi
```

`pi config` включает и выключает расширение. Чтобы оставить пакет установленным, но ничего из него не загружать:

```json
{
  "packages": [
    { "source": "git:github.com/kekma-dot/ayla-tools-compact", "extensions": [] }
  ]
}
```

Для удаления выполните `pi remove git:github.com/kekma-dot/ayla-tools-compact` и перезапустите Pi.

## Поведение

| Случай | Строка |
|---|---|
| Свёрнуто | 5 строк вывода и `… +N lines · ctrl+o`: перед хвостом и после начала |
| Раскрыто (`ctrl+o`) | До 400 строк и число оставшихся |
| Ошибка | 9 строк превью, глиф `✗`, у шелла виден конец с ошибкой |
| `bash` | Длительность от старта исполнения до результата, хвост вывода |
| `read` | `путь:от-до` при `offset` или `limit` и число строк |
| `grep`, `find`, `ls` | Сводка аргументов и число совпадений или записей |
| Пустой вывод | Строк тела нет |

## Ограничения

- Переоформлены только эти пять инструментов. `edit` и `write` сохраняют отрисовку Pi.
- Размеры превью, потолок в 400 строк и глифы заданы в исходнике, поэтому менять их нужно правкой расширения.
- Счётчики считают строки вывода, а не совпадения.
- ANSI-цвет в выводе инструментов вырезается, поэтому цветной вывод теряет цвет.
- Каждая строка обрезается по ширине терминала, включая широкие и управляющие символы.
- Это функция терминала. На то, что получает модель, она не влияет.

## Разработка

```sh
npm ci
npm run check   # TypeScript против деклараций Pi 1.3.0
npm test        # node:test
```

`npm test` упаковывает пакет, распаковывает готовый артефакт, загружает его через `DefaultResourceLoader` Pi и прогоняет renderer'ы, включая случай, когда своё расширение зарегистрировало собственный `bash` раньше.
